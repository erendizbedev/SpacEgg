# SpacEgg — Değişiklik Günlüğü
Sürüm kaynağı: `data/version.json`.

## 2.0.0 "Büyük Patlama" (versionCode 6)
- Yeni ürün kimliği: Evren Yaratma Simülatörü. Tohumdan evren, kesintisiz Evren→Galaksi→Sistem→Gezegen yakınlaşması.
- Zaman kontrolü (durdur, 1×–1000×), yıldız yaşam döngüsü, yörüngeler, kozmik olaylar, gezegen iklimi.
- Keşif hedefleri, günlük, kararlar; gerçek/basitleştirilmiş/kurgu etiketleri.
- Sürümlü kayıt, 3 yedek, dışa/içe aktarma, bozuk kayıt kurtarma.
- Yeni arayüz, eğitim, erişilebilirlik (hareket azaltma, yüksek kontrast, yazı ölçeği, liste görünümü), kalite kademeleri, fotoğraf modu.
- Ölçek bağlı yeni ses katmanı.
- Eski v1 oyunu Ayarlar'dan açılır; verilere dokunulmadı.
